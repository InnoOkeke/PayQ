# Aevum Builder Challenge #1 — Hackathon Documentation

> **Host:** QDay Network (`qday.io`)
> **Platform:** DoraHacks — [https://dorahacks.io/hackathon/qday/detail](https://dorahacks.io/hackathon/qday/detail)
> **Network:** QDay Aevum Testnet (Post-Quantum, EVM-Compatible Layer 2)

---

## Overview

The **Aevum Builder Challenge #1** is a global virtual hackathon challenging developers to build practical, stablecoin payment-related applications on the **QDay Aevum Testnet** using **`tUSD8`**. Successful participants can earn a fast track into the QDay mainnet builder program ahead of mainnet launch.

## Submission Requirements

1. **Open-Source Code:** Clean, readable code in a public GitHub repository.
2. **Aevum Integration:** Proof that the application actively uses QDay infrastructure (e.g., smart contracts deployed on Aevum Testnet, `tUSD8` settlement, ERC-8004 / QDay dApp integration).
3. **Live Deployment:** Working demo, prototype interface, or packaged Docker image.
4. **Project Documentation:** Problem statement, system architecture, core workflows, and tech stack.
5. **Video Pitch / Demo:** Required for top 5 finalists.
